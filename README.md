## 🏁 Getting Started

### 🧙 Requirements

- Java 8+ ☕  
- A brain (optional but recommended 🧠)  
- Maven (or use the magical wrapper) 🧙‍♂️  

### 🔧 Setup (aka "How to not mess this up")

```bash
git clone https://github.com/Meghraj2004/disaster-management.git
cd disaster-management
./mvnw clean install
./mvnw spring-boot:run
```

Now open your browser and pretend everything is working 🌈💻
